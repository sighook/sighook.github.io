Systems Engineering

Zeppe-Lin

Source-based GNU/Linux distribution and ongoing systems engineering project derived from CRUX. The native package stack is decomposed into contract-oriented components separating execution, application, durable state, resolution, reconciliation, and platform mechanisms.

Representative current work:

  • libpkgexec-linux — Linux execution backends with explicit isolation and resource contracts
  • libpkgapply and libpkgapply-posix — application, recovery, and POSIX mutation mechanisms
  • pkgctl — package control plane composing the native package-management boundaries
  • zeppe-lin-system — product composition and bootstrap

https://github.com/zeppe-lin

Pixload

Payload injection toolkit for image formats (JPEG, PNG, GIF, BMP, WebP).

  • Embeds arbitrary payloads into image structures
  • Useful for testing parser behavior and detection systems

The repository has about 1,300 stars and 250 forks on GitHub (August 2026).

https://github.com/sighook/pixload

pdf2hashcat

Maintained Python utility for extracting hashcat-compatible hashes from encrypted PDF files.

  • Supports PDF 1.1 through 1.7, including standard and AES encryption
  • Pure Python 3 with unit tests

https://github.com/sighook/pdf2hashcat
