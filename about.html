About

I am an application security engineer and systems programmer working at the intersection of source-code review, low-level software, network protocols, and vulnerability research.

My work focuses on understanding how systems actually behave under real conditions — by reading implementations, tracing data and authority across boundaries, and testing security assumptions. When source or protocol semantics are unavailable, I use reverse engineering to establish the missing behavior before drawing conclusions.

Focus Areas

  • Application security and source-code review
  • Vulnerability research and adversarial testing
  • Low-level systems (Linux, kernel interfaces, performance tuning)
  • Network protocols and traffic analysis
  • Security tooling and automation

Approach

  • Inspect implementations before inferring behavior
  • Reproducible research and verifiable results
  • Reverse engineer when source or protocol semantics are unavailable
  • Upstream-first contributions where possible
  • Minimal, composable tooling
