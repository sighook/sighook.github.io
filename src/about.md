# About

I'm a security engineer and systems programmer with a background in
Linux infrastructure, protocol work, and application security. I worked
at Salt Edge on application security and bug bounty triage; since 2020
I've worked independently on security research and software engineering.

I spend a lot of time reading source. When a system behaves unexpectedly,
I want to understand the path from input to decision: what was trusted,
what state changed, which checks ran, and which ones did not.

## How I work

I prefer a small, reproducible test over a long list of hypothetical
issues. I try to separate the observed failure from its possible impact,
and a proposed fix from a verified one. When possible, I work with
maintainers to get the correction upstream.

My main interests are application security, source-code review, protocol
analysis, vulnerability research, and low-level systems. The details
are in [Research](research.html) and [Projects](projects.html); my
employment history is in the [CV](cv.html).

I also write about the less tidy side of systems work: assumptions that
outlive their original code, interfaces that hide who owns a decision,
and failures that only become obvious after years of operation.
[The Fieldbook](https://github.com/zeppe-lin/fieldbook) is where I
explore that at length.
